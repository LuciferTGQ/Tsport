# Tsport 1.0.1 Android 自用测试版

安装文件：`Tsport-1.0.1-debug.apk`，约 4.3 MB，Android 8.0 及以上。

与 1.0.0 使用相同应用包名和签名，可直接覆盖安装以保留原有训练、体重记录。建议先导出备份，不需要卸载旧版。

## 本次更新

- 后台休息改为原生用户闹钟，由 Android 接收器直接发出通知，不依赖应用界面继续运行。缺少通知或精确闹钟权限时明确提示，不再安排可能延迟的普通通知。
- 设置新增「30 秒后测试后台提醒」，便于实际切后台或锁屏测试。
- 日历新增「休息」标签，自动补入旧数据；休息日不会算作运动日。
- 达到目标组数后，动作卡片和底部计时器均提供「完成该动作」。完成后保留记录、关闭该动作计时并取消提醒，也可以再加练。

## 安装与后台提醒测试

1. 将 APK 发送或复制到手机，在文件管理器中打开并覆盖安装。
2. Tsport → 偏好设置 → 开启「休息结束系统通知」，允许通知权限。
3. 点击「开启准时提醒权限」，在系统「闹钟与提醒」设置中允许 Tsport，然后返回应用。
4. 选择声音和震动，点击「30 秒后测试后台提醒」，立即切换到其他应用，等待 30 秒。应收到系统通知，点击应返回训练，不会自动开始下一组。也可另测锁屏。
5. 正式训练结束一组后，计时卡片应显示「Android 系统提醒已安排」。延长休息重排提醒；跳过、关闭计时、完成动作、开始下一组或关闭提醒会取消原休息提醒。

用户设备为 iQOO Neo9 Pro。若通知出现在通知栏但没有横幅/震动，请在手机 Tsport 通知设置中检查悬浮通知、锁屏通知、声音和震动。若后台仍无通知，请在手机设置中搜索 Tsport 的后台耗电/电池管理，检查是否限制后台活动；具体名称随 OriginOS 版本变化。

安排休息期间系统可能显示闹钟图标。勿扰、强行停止、手机重启及厂商省电策略仍可能影响提醒。手机重启后不补发旧提醒，重新进入应用会安排尚未结束的休息。
