# Tsport Android 自用测试版

安装文件：`Tsport-1.0.0-debug.apk`，约 4.3 MB，Android 8.0 及以上。

1. 将 APK 发送或复制到手机，在手机文件管理器中打开安装；按系统提示允许该文件来源安装应用。
2. 打开 Tsport → 偏好设置 → 开启「休息结束系统通知」，允许通知权限。
3. 点击「开启准时提醒权限」，在 Android「闹钟与提醒」设置中允许 Tsport，然后返回应用。
4. 选择声音和震动，点击「发送测试提醒」，检查通知横幅与震动；点击通知应返回训练界面。
5. 正式训练结束一组后，等待显示「Android 系统提醒已安排」，即可切到其他应用。休息结束时由 Android 发送通知，下一组仍需手动开始。

若无横幅或震动，在手机系统的 Tsport 通知设置中允许横幅、声音和震动。勿扰、强行停止或厂商省电规则可能影响通知。

这是本机 debug 签名的自用测试包。构建、APK v2 签名、权限和资源校验均通过；14 项逻辑测试与 6 项浏览器/原生桥接模拟测试通过。尚未连接真实 Android 手机验证震动、锁屏及厂商电池策略。

训练与体重数据离线保存在应用中。原网页记录需先导出 JSON，再在 Android 应用中恢复；卸载或清除应用数据前请备份。
